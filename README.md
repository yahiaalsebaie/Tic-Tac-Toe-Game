# Tic-Tac-Toe Game

A Windows Forms-based Tic-Tac-Toe game built with C# and .NET Framework 4.7.2. Play against another player or challenge the computer AI.

## Features

- **Single Player Mode**: Play against a computer opponent with AI logic
- **Multiplayer Mode**: Challenge another player on the same machine
- **Customizable Rounds**: Set the number of rounds you want to play
- **Game Statistics**: Track wins and results across multiple rounds
- **Custom Cursors**: Enhanced user experience with themed cursor graphics
- **Clean UI**: Intuitive Windows Forms interface with visual feedback

## System Requirements

- Windows OS
- .NET Framework 4.7.2 or higher
- Display resolution: 1024x768 or higher

## How to Play

1. **Start the Application**: Launch the game
2. **Enter Player Names**: Input names for both players (or leave Player 2 as "Computer" for AI mode)
3. **Toggle Computer Mode**: Check the "Computer" checkbox to play against AI
4. **Set Number of Rounds**: Use the numeric control to select how many rounds to play
5. **Click "Start Game"**: Begin playing
6. **Make Your Move**: Click on an empty square to place your mark (X or O)
7. **View Results**: After each round, game results are displayed

## Controls

- **Start Game Button**: Begins the game with selected settings
- **Minimize Button**: Minimizes the application window
- **Close Button**: Closes the application
- **Computer Checkbox**: Toggle between multiplayer and single-player (AI) modes
